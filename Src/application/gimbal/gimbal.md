# gimbal

## 工作流程

`GimbalTask()` 当前流程：

1. 从消息中心获取gimbal_cmd话题的消息
2. 根据消息中的控制模式进行模式切换，如果急停则关闭所有电机
3. 按模式设置 yaw/pitch 参考值并写入电机
4. 设置反馈数据，包括yaw电机的绝对角度和imu数据
5. 推送反馈数据到gimbal_feed话题下

## 已完成迁移点

1. yaw/pitch 电机 CAN 与 ID 已统一读取 `robot_def.h`。
2. 云台 PID 参数（角度环/速度环）已参数化。
3. pitch 指令限幅接口已加入，并由宏开关控制。

## 当前限制

1. 重力补偿与高级前馈仍为后续增强项。
2. 当前已满足 infantry 基线控制，但上车仍需按机械结构做零点/方向/限位校准。
