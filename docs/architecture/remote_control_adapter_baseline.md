# 遥控适配器与步兵输入基线

更新日期：2026-07-20

## 1. 设计结论

正式步兵固件在编译期只选择一个遥控后端，ET08、DT7 和 VT 不同时初始化，
不进行运行时仲裁、热备接管或自动回退。当前默认选择 ET08。

数据依赖固定为：

```text
ET08 / DT7 / VT 协议驱动
        -> 对应 Backend（只做设备字段适配）
        -> RemoteControlState（统一当前电平）
        -> RemoteControlAdapter（统一边沿与重连基线）
        -> 步兵输入 Profile（机器人语义映射）
        -> SafetyManager（最终输出许可）
        -> 底盘 / 云台 / 发射执行层（物理限幅与电机命令）
```

层间职责不能倒置：

- 协议驱动只负责收帧、校验、超时和一致快照。
- Backend 只把物理摇杆、拨杆、旋钮、键盘、鼠标和按钮转换成统一状态。
- `RemoteControlAdapter` 只生成按下、释放和开关变化边沿，不包含步兵模式。
- 步兵 Profile 决定某个开关代表跟随、陀螺或发射模式。
- Pitch 机械范围、底盘总速度和轮速饱和只在执行层拦截，对遥控、视觉和后续自动控制一视同仁。

## 2. 目录和接口

```text
components/devices/remote/
|-- remote_control_state.h
|-- remote_control_adapter.hpp
|-- et08/
|   |-- et08_remote.c/.h
|   |-- et08_control_layout.h
|   `-- et08_backend.hpp
|-- dt7/
|   |-- dt7_remote.c/.h
|   `-- dt7_backend.hpp
`-- vt/
    |-- vt_remote.c/.h
    `-- vt_backend.hpp

applications/infantry/command/
|-- infantry_input.cpp
|-- infantry_input.h
`-- infantry_et08_input_profile.cpp/.hpp
```

`RemoteControlState` 统一提供：

- 16 个模拟轴的原始值、归一化值和有效掩码；
- 8 个开关的上/中/下位置、有效掩码和变化掩码；
- 键盘当前值、按下沿和释放沿；
- 鼠标 XYZ、按钮能力、当前值、按下沿和释放沿；
- 链路在线、数据有效、failsafe、丢帧、样本序号和采样时间。

旋钮和拨轮属于标准模拟轴，额外通道属于辅助轴，因此应用无需感知 SBUS、
DBUS 或 VT 21 字节帧的具体布局。

## 3. 编译期唯一选择

选择项位于 `applications/infantry/config/infantry_config.h`：

```c
#define INFANTRY_REMOTE_BACKEND INFANTRY_REMOTE_BACKEND_ET08
```

可选值只有：

| 配置 | 后端 | 默认超时 |
| --- | --- | ---: |
| `INFANTRY_REMOTE_BACKEND_ET08` | ET08 + RF206S，SBUS，USART3 | 100 ms |
| `INFANTRY_REMOTE_BACKEND_DT7` | DT7 + DR16，DBUS，USART3 | 100 ms |
| `INFANTRY_REMOTE_BACKEND_VT` | VT03/VT13，USART6 | 200 ms |

无效值直接编译失败；调试串口与所选遥控串口冲突也直接编译失败。正式 ET08
镜像的符号表只包含 ET08 驱动，不包含 DT7/VT 遥控初始化函数。

## 4. ET08 步兵映射

| 控件 | 位置 | 步兵语义 |
| --- | --- | --- |
| SA | 下 | 操作者安全门关闭，全局电机输出禁止 |
| SA | 上 | 打开电平安全门；硬故障均清除后允许输出 |
| SB | 下 | 云台控制、底盘跟随云台 |
| SB | 中 | 视觉自瞄预留；当前安全退化为普通跟随，不启用未完成视觉闭环 |
| SB | 上 | 小陀螺模式，云台保持方向，底盘旋转 |
| SC | 下 | 发射禁用，摩擦轮和拨弹停止 |
| SC | 中 | 单发模式，摩擦轮启用 |
| SC | 上 | 连发模式，摩擦轮启用 |
| SD | 下 | 扳机释放 |
| SD | 上 | 扳机触发 |

左摇杆生成云台坐标系底盘平移意图，右摇杆生成云台 Yaw/Pitch 速度意图。
Profile 只输出 `[-1, 1]` 无量纲意图，不包含 m/s、rad/s、deg/s、电机转速或机械限位。
ET08 配置只保留中位、量程、死区和在线截止等设备校准参数。

单发只消费 SD 从下到上的变化沿。SD 保持上位不会按时间间隔重复单发；连发则要求
SC 上位且 SD 持续上位。

## 5. 安全门与掉线策略

当前正式步兵调试配置把 SA 作为直接电平门：遥控数据有效、初始化完成、INS 和关键任务
正常时，SA 上位直接进入 `ACTIVE`；SA 下位立即关闭全局输出。SB/SC/SD 和摇杆状态不参与
解锁资格，因此操作手可先选择模式或带着非零摇杆打开 SA。

遥控掉线、failsafe 或无效开关仍立即触发停机。链路恢复且 SA 保持上位时会按电平门
自动恢复；调试时必须保证车辆离地、操作手可随时下拨 SA。通用 `SafetyManager` 仍保留
严格重使能策略，后续比赛阶段可通过配置恢复“安全姿态→新 SA 上拨沿”。

单个电机掉线不属于当前整车安全门：设备层记录错误，并只把掉线电机的输出槽归零；
其他在线电机继续执行。INS、初始化和关键任务仍属于整车安全条件。

SA 下位不是普通零速度命令：控制任务先关闭 DJI 全局输出门，再向底盘、云台和发射
发布停止命令，其效果与遥控离线一致。20 ms 控制周期和 100 ms ET08 截止共同决定
断链软件停机延迟，实板必须测量最坏值。

## 6. 执行层保护

- 底盘执行层把满意图映射到由 `M3508_ROTOR_SPEED_LIMIT_RAD_S`、19.2032 减速比和轮径推导出的
  约 2.045 m/s 平移上限；纯旋转上限约 12.03 rad/s。
- 平移和旋转叠加导致车轮超过电机速度能力时，四轮共同等比例缩放，不逐轮削顶破坏方向。
- Yaw 满意图为 828 deg/s，Pitch 满意图为 540 deg/s，均只在云台执行层展开。
- Pitch 在 IMU 角接近 `[-25, 35] deg` 的 3 deg
  软区间内线性降速。
- Pitch 手动速度、释放制动和角度保持目标都经过同一执行层边界；角度目标会根据
  当前 IMU 角与方向符号推算目标姿态，再截断到硬边界，不能用一次大步进跨过限位。
- 底盘运动学和 Pitch 限位对 NaN/无穷值按失效关闭处理，不向电机层传播非法参考。
- `GIMBAL_PITCH_IMU_DIRECTION_SIGN` 必须通过悬空/卸载实测确认；方向错误时不得继续顶限位测试。

关键调参位置见[步兵底盘与云台调参说明](../motor/infantry_chassis_gimbal_tuning.md)。

## 7. C/C++ ABI 与链接约束

- C++ 仅用于状态适配和纯映射，不使用动态分配、异常、RTTI 或静态析构注册。
- 所有供 C 与 C++ 共同调用的 C 头均使用 `extern "C"` 保护。
- `Input_Init()`、`Input_GetData()` 等应用入口保持 C ABI，现有 C FreeRTOS 任务无需改调用方式。
- 正式 ELF 显式使用 C++ 链接驱动。
- 链接后拒绝 `new/delete`、`__cxa_*`、异常展开、C/FreeRTOS 堆和 libc 格式化符号。

## 8. 自动验证与实板门禁

主机测试已覆盖：

- 首帧无伪边沿、正常按下/释放边沿和断线后重连基线；
- ET08 四轴、SA/SB/SC/SD、单发沿、连发电平和安全门最高优先级；
- 严格策略下的安全姿态与新 SA 上拨沿行为；
- 当前电平门下 SA 上位直接激活、SA 下位直接停机；
- INS 的 rad/s 角速度进入云台电机速度环前统一转换为 deg/s；
- Pitch 速度/角度软硬限位、超大角度目标、非法浮点输入和方向符号；
- 底盘坐标旋转、平移向量限幅、全向轮逆解和共同饱和。

实板仍必须依次确认：

- [ ] 遥控日志中的四开关位置与物理上/中/下完全一致；
- [ ] SA 下位、关遥控器和接收机 failsafe 都能让全部电机停止；
- [ ] 重连且 SA 保持上位时按当前电平策略恢复，SA 下位时绝不输出；
- [ ] 任一单电机掉线只隔离自身，不阻塞其他在线电机；
- [ ] 四轮正方向、底盘坐标变换和跟随闭环方向正确；
- [ ] SB 中位不触发未完成自瞄动作，SB 上位小陀螺方向和速度安全；
- [ ] Yaw、Pitch 摇杆方向正确，Pitch 限位方向符号正确；
- [ ] 在拆弹/禁发条件下先完成底盘与云台测试，再验证摩擦轮和拨弹。
