# 轮腿（髋部双电机 + 中轴齿轮 + 连杆驱膝 + 轮端驱动）建模与调参记录

本文面向你当前这种结构：两台关节电机固定在髋座/机身侧，通过链条驱动中轴上的两个从动齿轮；其中一路直接驱动髋关节（带动大腿），另一路通过连杆机构传动到膝关节（带动小腿）；末端为轮（轮毂电机或轮电机+减速箱）。

补充硬件背景（用于参数测量/估力/限流）：关节电机 `DM8009P`；轮端电机 `3508 + 改减速箱`。

---

## 1. 结构草图与结构特点

### 1.1 草图（侧视，示意，强调“串联腿拓扑”）

```
    机身/髋座（固定基座，簧上）
┌──────────────────────────────┐
│      [DM8009P]      [DM8009P] │  两关节电机（固定在机身侧）
└──────────┬───────────┬───────┘
           │链条/齿轮    │链条/齿轮
           v             v
       (传动到髋)     (传动到膝：中轴齿轮+连杆)
           │             │
           v             v
          o HIP ──────── o KNEE ─────── (Wheel, 3508+gear)
            大腿（串联）     小腿（串联）        轮端驱动
──────────────────────────────────────────────────────── 地面
                               ↑ GRF/法向支持力 N
```

### 1.2 结构特点（工程上最重要的点）

- 这是“串联腿”拓扑：从运动学/控制视角，腿的广义坐标就是 `q = [q_hip, q_knee]`，足端位姿由 `FK(q_hip, q_knee)` 决定；膝部的多连杆/齿轮只是**远程传动机构**，不把腿变成并联腿。
- 电机“上置”：关节电机固定在机身/髋座侧，腿摆动的随动质量更小，通常更利于响应和耐冲击。
- 膝关节为“远程连杆传动”：膝的等效传动比/力臂一般随姿态变化明显，导致“同样电流/同样电机力矩，在不同角度产生的膝关节力矩不同”。
- 可能存在耦合：如果连杆闭环跨到机身固定点或跨髋轴，膝角可能不仅依赖电机2角度，也依赖髋角（需要二维查表/几何解算）。
- 传动非理想项更突出：链条回程间隙、张紧状态变化、摩擦、柔顺性会直接影响力矩估计与触地/离地判断。
- 末端为轮：轮地接触可产生滑移；“触地=1”不等价于“无滑移”，姿态/里程计要考虑打滑检测与融合。

## 2. 要测算哪些参数？如何建模？

建议把建模分三层：**几何/运动学**、**传动映射**、**动力学/估力**。先把前两层做准，第三层按需求逐步加。

### 2.1 必测参数清单（按优先级）

#### A) 几何与安装（必须）

- 关键铰点坐标（建议直接从 CAD 导出或标定）：
  - 髋轴 `HIP`、膝轴 `KNEE`、轮轴 `WHEEL` 的相对位置
  - 膝传动连杆机构的所有铰点与杆长（闭环方程需要）
- 大腿长度、小腿长度、轮轴相对小腿的偏置（如果轮轴不在小腿端点）
- 轮半径 `R_wheel`（含轮胎实际外径；更建议滚动标定而非仅用图纸值）
- 关节机械限位角（安全必须）：髋、膝（以及若有踝/摆臂）
- 编码器零位与方向：电机侧角度零点、关节侧角度零点（建议统一“站立标称姿态”为零参考）

#### B) 传动参数（必须）

- 链条传动比：主动/从动齿数（或齿轮比），两路分别记录
- 膝连杆机构几何：用于得到
  - 位置映射：`q_knee = f(θ2[, q_hip])`
  - 速度/力矩映射：`Jt = ∂q/∂θ`
- 传动效率 `η`（可先用常数近似，后续再细化）：
  - 链条效率、轴承效率、连杆机构效率
- 回程间隙/死区（用于控制与估力鲁棒性）：可用“正反扫角”测 hysteresis

#### C) 质量与惯量（建议）

- 机身侧总质量、质心位置（对平衡控制很关键）
- 腿侧随动质量（髋轴以下）：
  - 大腿/小腿/轮组件质量
    -（可选）分段转动惯量（不做全动力学也能用来估计冲击/滤波带宽）
- 轮端等效质量（用于法向/离地粗判）：轮、减速箱、支架等“随轮端上下动”的部分

#### D) 电机与电气（建议，但做估力/限流时很关键）

- `DM8009P`：力矩常数 `K_t`、额定/峰值电流、驱动器上报的力矩估计是否可信、摩擦补偿策略
- `3508+gear`：减速比 `i_g`、力矩常数 `K_t`、电流上限、速度环带宽、齿隙与效率

> 注：如果驱动器能直接提供“估计输出力矩/电机侧力矩”，也要确认它的定义是在电机轴还是减速箱输出端。

### 2.2 建模：把系统拆成两个雅可比

将变量分成三组：

- 电机侧角度：`θ = [θ1, θ2]^T`（两台 DM8009P 的编码器角）
- 关节侧角度：`q = [q_hip, q_knee]^T`
- 足端（轮心）在腿坐标系的位姿：`x = [x, y]^T`（平面模型），或 `x=[x,y,z]`（3D）

核心是两层映射：

1) **传动映射（电机→关节）**

   - 位置：`q = g(θ)`（膝一般非线性，可能还与髋耦合）
   - 雅可比：`Jt(θ) = ∂q/∂θ`
2) **腿运动学（关节→足端）**

   - 正运动学：`x = FK(q)`
   - 雅可比：`Jleg(q) = ∂x/∂q`

这两层合起来就能做大多数你关心的事：

- 姿态/足端位置解算：`q -> x`
- 足端速度解算：`x_dot = Jleg(q) q_dot`
- 力矩/地面反力估计（准静态/低频）：用功率守恒把力矩一层层“反解回去”

### 2.3 传动映射怎么做（强烈建议“查表/LUT”先跑起来）

因为膝是连杆机构，解析推导经常又长又容易错，工程上更稳的是：

1. 离线从 CAD 或标定数据采样：
   - 固定髋角 `q_hip` 在几个代表姿态（如 -20°/0°/20°）
   - 扫 `θ2` 全行程，记录得到 `q_knee`
2. 生成 `q_knee = LUT(θ2, q_hip)`（若无耦合则退化为 `LUT(θ2)`）
3. 在线插值得到 `q_knee`
4. `Jt` 用数值差分得到（注意滤噪与边界）：
   - `∂q_knee/∂θ2 ≈ (LUT(θ2+Δ)-LUT(θ2-Δ))/(2Δ)`

髋通道通常可用线性：

- `q_hip = a*θ1 + b`，`∂q_hip/∂θ1 = a`

## 3. 如何进行姿态解算（状态估计/接触判断）

这里“姿态”建议拆成三件事：**机身姿态**、**腿构型**、**接触状态与轮地关系**。

### 3.1 机身姿态（IMU）

- 机身姿态角（roll/pitch/yaw）优先用 IMU 融合（互补/Mahony/Madgwick/EKF 任选其一）。
- 关键是做对：
  - IMU 安装方向/坐标系一致性（机体系定义）
  - 陀螺零偏（开机静置校准或在线估计）

### 3.2 腿构型（电机角→关节角→足端位姿）

1) 读电机编码器角：`θ1, θ2`
2) 通过传动映射得关节角：`q = g(θ)`（髋线性 + 膝 LUT/几何）
3) 用 `FK(q)` 得轮心位置 `(x,y)`、等效腿长 `L`、等效腿角 `α`

如果你还需要轮相对地面的“几何高度”，要定义一个地面基准（通常来自接触检测 + 轮半径约束）。

### 3.3 接触状态与地面反力（推荐“多源融合 + 滞回”）

轮腿最常见的状态误判来自：打滑、链条回差、摩擦导致的力矩估计漂移。因此建议使用至少两类证据：

#### A) 由电流/力矩反算的 GRF（低频可信）

电机侧力矩（需要 `K_t` 或驱动器力矩估计）：

- `τ_m = K_t * i`（分别对两台 DM8009P）

传到关节侧（忽略或粗略补偿摩擦）：

- `τ_q ≈ (Jt(θ)^(-T)) * (η * τ_m)`

关节力矩反解足端力（平面 2D）：

- `F ≈ (Jleg(q)^(-T)) * τ_q`

取竖直/法向分量作为 `ground_reaction_force`，并做低通滤波。

> 经验：链条+连杆的摩擦/回差会让“绝对力值”偏差较大，但“触地瞬间的变化趋势”通常仍然好用。

#### B) 由运动学/IMU 的“瞬态证据”（高频可信）

- 轮/足端速度在触地瞬间的突变（尤其是竖直方向速度由负变近零）
- 机身竖直加速度/冲击（IMU `a_z`）
- 轮速与机身速度不一致（滑移检测）

#### C) 判定策略

- 用滞回：`TouchDownThreshold` > `LiftOffThreshold`
- 多数表决：GRF 过阈值、速度突变、力矩突变满足其二即可判触地

## 4. 如何调参（推荐的调参顺序与方法）

调参建议按“从确定性到不确定性、从底层到上层”的顺序推进。

### 4.1 上电前：先把安全参数固定住

- 关节机械限位角（软件硬限 + 软限缓冲）
- 电机电流/力矩上限：
  - `DM8009P`：先用低电流上限做联调，确认方向/零位/链条张紧无异常后再逐步放开
  - `3508+gear`：低电流起步，避免减速箱齿隙冲击
- 速度上限（尤其是膝连杆在某些角度传动比会很大，容易“电机角速度不大但关节角速度暴涨”）

### 4.2 第一步：标定“零位、方向、映射”

目标：让“你以为的角度”和“真实构型”一致。

- 髋：确认 `θ1` 增加时 `q_hip` 的正方向是否一致
- 膝：用 LUT/几何解算，抽 5~10 个姿态点对照实测角度（量角器/视觉/治具）
- 轮：确认轮半径与轮速方向，做一次地面滚动标定（推行一段距离校准 `R_wheel` 或编码器比例）

验收标准：

- 给定电机角度变化，腿构型变化方向正确
- FK 计算的轮心轨迹与实际运动一致（误差随行程不发散）

### 4.3 第二步：把“膝的传动比变化”纳入控制直觉

膝连杆机构的常见现象：

- 某些角度 `∂q_knee/∂θ2` 很小：电机转很多，膝角变化不大（看起来“很肉”）
- 某些角度 `∂q_knee/∂θ2` 很大：膝角对电机角极敏感（容易抖、容易冲限位）

调参策略：

- 对膝的角度环增益做“随传动比调度”：增益与 `|∂q/∂θ|` 反比（传动比大时减小增益）
- 或者干脆在电机侧闭环，但把目标从“电机角”换成“关节角映射后的电机角”（仍需要 LUT）

### 4.4 第三步：估力/触地阈值调参（先可用，再精）

1) 先只做趋势可靠：

- 先用“力矩变化/速度突变/IMU 冲击”做触地，GRF 只作辅助

2) 再把 GRF 做成可用：

- 引入 `Jt`（尤其是膝的角度相关倍率）
- 加摩擦补偿（至少库仑 + 粘性）
- 触地阈值按“站立单腿承重的 20%~30%”起步，再根据误报/漏报调整

### 4.5 第四步：平衡与行走（上层控制）

不依赖特定控制器形式（PID/LQR/MPC 都行），建议共性步骤：

- 先只调“站立保持”：
  - 足端高度/等效腿长保持
  - 机身 pitch/roll 稳定
- 再叠加轮控制（3508）：
  - 轮速环先慢（带宽低），保证不打滑、不拉扯姿态
  - 再逐步提高带宽与加速度限制
- 最后上动态动作（跳跃/快速加减速）：
  - 重点看触地误判、传动回差导致的抖动、减速箱冲击

## 5. 注意事项（强烈建议逐条对照检查）

### 5.1 机构与奇异位形

- 膝连杆可能存在“力臂趋近 0”或“速度比陡增”的角度区间，表现为：
  - 控制增益同样时突然抖/突然软
  - 电机电流很大但膝力矩不上去，或相反
- 建议在 LUT 里同时输出并监控 `r(θ)=∂q_knee/∂θ2`，在 `r` 过大/过小处限幅、降速、禁入。

### 5.2 回差、柔顺与摩擦

- 链条张紧不足会导致触地瞬间“先空行程再受力”，估力会延迟且不稳定。
- 连杆铰点间隙会让膝角反解/控制出现 hysteresis；调参时要在同一方向靠近目标点测试。
- 做估力时不要迷信绝对值：先让“变化趋势”和“触地时间点”可靠，再追求力值准确。

### 5.3 轮地接触与滑移

- 轮速≠地速：加速/转弯/低摩擦地面会打滑；姿态解算/里程计要考虑滑移检测（轮速与 IMU/视觉/期望加速度不一致）。
- 改减速箱的 3508：注意齿隙与冲击，做加速度限幅、速度环带宽别一上来就拉满。

### 5.4 电机能力边界与热

- `DM8009P`：优先用力矩/电流控制做底层保护；在膝传动比高的区间尤其容易过流或过热。
- `3508+gear`：长时间大扭矩低速更容易热，必要时做温升限扭。

### 5.5 建议的最小数据记录（便于快速定位问题）

- `θ1, θ2`（电机角）、`q_hip, q_knee`（解算角）、`∂q_knee/∂θ2`
- 电机电流/力矩估计（两关节电机 + 轮电机）
- IMU：`roll/pitch/yaw`、角速度、竖直加速度
- 接触状态：触地/离地判据的各分量（力、速度突变、力矩突变）

## 附：一套“从 0 到可站立/可跑”的最短路线（建议执行顺序）

1) 做好限位/限流/急停
2) 标定髋线性映射与膝 LUT（先把角度解算做准）
3) 验证 FK：轮心轨迹与实际一致
4) 上最基础的站立控制（慢、稳、不过流）
5) 加入轮速控制（3508）并限制加速度
6) 加入触地/离地融合判定（带滞回）
7) 再逐步提高动态动作与控制带宽
