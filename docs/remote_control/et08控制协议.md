# ET08遥控控制协议

本文档基于 ET08 + RF206S 的实测结果整理，用于后续固件解析和控制逻辑设计。

## 通道/键位映射

ET08 共有 8 个通道。通道值为 SBUS 原始数值，以下范围为实测结果。

### 数值范围

- 摇杆: 最大值 1694, 最小值 -353, 中值 1024
- 旋钮: 最大值 1694, 最小值 -353, 中值 1024
- 拨杆(2 级 + 3 级叠加): 1896, 1694, 1493, -151, -353, -554

默认方向定义:
- 上为正, 下为负
- 左为正, 右为负
- 旋钮顺时针为正, 逆时针为负

### 通道分配表

| 通道 | 名称 | 方向 | 说明 |
| --- | --- | --- | --- |
| CH1 | J1 | 右摇杆左右 | 右摇杆 X |
| CH2 | J2 | 右摇杆上下 | 右摇杆 Y |
| CH3 | J3 | 左摇杆上下 | 左摇杆 Y |
| CH4 | J4 | 左摇杆左右 | 左摇杆 X |
| CH5 | SA + SB | 2 级拨杆 + 3 级拨杆 | 6 档组合: 1896, 1694, 1493, -151, -353, -554 |
| CH6 | SD + SC | 2 级拨杆 + 3 级拨杆 | 6 档组合,数值同上 |
| CH7 | LD | 左旋钮 | 连续值 |
| CH8 | RD | 右旋钮 | 连续值 |

## 控制逻辑(暂定)

- 左摇杆: 平移
- 右摇杆左右: 旋转方向
- 右摇杆上下: 待定
- 拨杆模式设置: 待补充
