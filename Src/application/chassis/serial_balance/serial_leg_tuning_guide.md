# 串联腿控制调参指南

## 概述

本指南详细说明串联腿控制系统的参数调节方法，包含20项关键参数和58个调参要点。串联腿控制比并联腿更复杂，需要更精细的参数调节。

## 机械参数调节

### 1. 连杆长度参数

**参数1-3：大腿/小腿/足部长度**
- `SERIAL_THIGH_LENGTH` (0.20m) - 大腿长度
- `SERIAL_SHANK_LENGTH` (0.18m) - 小腿长度  
- `SERIAL_FOOT_LENGTH` (0.08m) - 足部长度

**调参要点1-3：**
1. 使用CAD图纸精确测量各连杆长度
2. 考虑关节中心到连杆质心的距离
3. 误差应控制在±2mm以内

**调节方法：**
```c
// 根据实际机械尺寸调整
#define SERIAL_THIGH_LENGTH    0.20f  // 实测大腿长度 [m]
#define SERIAL_SHANK_LENGTH    0.18f  // 实测小腿长度 [m] 
#define SERIAL_FOOT_LENGTH     0.08f  // 实测足部长度 [m]
```

### 2. 质量参数

**参数4-6：连杆质量**
- `SERIAL_THIGH_MASS` (0.8kg) - 大腿质量
- `SERIAL_SHANK_MASS` (0.6kg) - 小腿质量
- `SERIAL_FOOT_MASS` (0.3kg) - 足部质量

**调参要点4-6：**
4. 使用电子秤测量各连杆质量
5. 包含电机、减速器等附属部件质量
6. 考虑质心位置对动力学的影响

### 3. 惯量参数

**参数7-9：转动惯量**
- `SERIAL_THIGH_INERTIA` (0.015kg·m²) - 大腿惯量
- `SERIAL_SHANK_INERTIA` (0.008kg·m²) - 小腿惯量  
- `SERIAL_FOOT_INERTIA` (0.002kg·m²) - 足部惯量

**调参要点7-9：**
7. 使用摆动法测量转动惯量
8. 考虑电机转子惯量的折算
9. 惯量误差对控制精度影响显著

### 4. 关节限位参数

**参数10-15：关节角度限位**
- 髋关节：±45°
- 膝关节：0°~135°  
- 踝关节：±30°

**调参要点10-15：**
10. 机械限位角度减去安全余量5°
11. 考虑运动学奇异点位置
12. 左右腿限位对称设置
13. 软件限位应比机械限位严格
14. 记录限位触发时的电机电流
15. 设置渐进式限位保护

## 控制参数调节

### 5. LQR控制器参数

**参数16-21：LQR反馈增益**
- `k_theta` (80.0) - 角度反馈增益
- `k_theta_dot` (15.0) - 角速度反馈增益  
- `k_length` (200.0) - 腿长反馈增益
- `k_length_dot` (25.0) - 腿长变化率反馈增益
- `k_pitch` (60.0) - 俯仰角反馈增益
- `k_pitch_dot` (8.0) - 俯仰角速度反馈增益

**调参要点16-21：**
16. 从较小增益开始，逐步增大
17. 观察系统响应的超调量
18. 平衡稳态误差与响应速度
19. 不同步态模式下增益需要调整
20. 记录临界稳定时的增益值
21. 考虑增益调度的非线性特性

**调节步骤：**

1. **初始设置：**
```c
// 保守的初始增益
serial_lqr_gains.k_theta = 40.0f;        // 减半设置
serial_lqr_gains.k_theta_dot = 8.0f;     
serial_lqr_gains.k_length = 100.0f;    
serial_lqr_gains.k_length_dot = 12.0f;  
serial_lqr_gains.k_pitch = 30.0f;      
serial_lqr_gains.k_pitch_dot = 4.0f;   
```

2. **逐步调节：**
- 首先调节角度增益k_theta，直到出现轻微振荡
- 然后增加角速度增益k_theta_dot抑制振荡
- 接着调节腿长相关增益
- 最后微调俯仰角增益

**调参要点22-28：**
22. 使用阶跃响应测试调节效果
23. 记录不同增益下的稳定时间
24. 观察电机输出是否饱和
25. 检查机械振动和噪声水平
26. 验证参数鲁棒性
27. 测试不同地面条件下的性能
28. 记录最优参数组合

### 6. 步态参数调节

**参数29-34：步态时序参数**
- `swing_time` (0.4s) - 摆动相时间
- `stance_time` (0.6s) - 支撑相时间  
- `step_height` (0.08m) - 步高
- `step_length` (0.15m) - 步长
- `touchdown_velocity` (0.5m/s) - 触地速度
- `lift_off_velocity` (0.3m/s) - 离地速度

**调参要点29-34：**
29. 摆动时间应保证足部落脚前达到目标位置
30. 支撑时间需要足够完成机体推进
31. 步高应越过地面障碍物
32. 步长与期望速度成正比关系
33. 触地速度影响落地冲击大小
34. 离地速度决定腿部离地时机

**不同速度下的推荐参数：**

| 速度范围 | 步态模式 | 摆动时间 | 支撑时间 | 步高 | 步长 |
|---------|----------|----------|----------|------|------|
| 0-0.3 m/s | 平衡 | - | - | - | - |
| 0.3-0.8 m/s | 行走 | 0.4s | 0.6s | 0.06m | 0.12m |
| 0.8-1.2 m/s | 小跑 | 0.3s | 0.4s | 0.08m | 0.18m |
| 1.2-1.8 m/s | 跳跃 | 0.25s | 0.35s | 0.10m | 0.25m |

**调参要点35-40：**
35. 从低速步态开始测试
36. 逐步增加速度并调整参数
37. 观察步态过渡的平滑性
38. 记录不同地面的适应性
39. 调整参数避免步态失稳
40. 验证参数对负载变化的鲁棒性

### 7. 电机控制参数

**参数41-45：关节电机PID参数**
- `Kp` (2.0) - 位置环比例增益
- `Kd` (0.1) - 位置环微分增益  
- `MaxOut` (8.0A) - 最大输出电流
- `DeadBand` (0.001rad) - 死区范围
- `Derivative_LPF_RC` (0.02s) - 微分滤波时间常数

**调参要点41-45：**
41. 串联腿需要更强的位置控制
42. 微分增益抑制超调和振荡
43. 最大输出应留有余量避免饱和
44. 死区设置平衡精度与抖动
45. 微分滤波抑制高频噪声

**调节方法：**
```c
// 关节电机PID参数
.angle_PID = {
    .Kp = 2.0f,      // 比例增益 - 调参要点41
    .Kd = 0.1f,      // 微分增益 - 调参要点42
    .Ki = 0.0f,      // 积分增益（位置环通常不用）
    .MaxOut = 8.0f,  // 最大输出 - 调参要点43
    .DeadBand = 0.001f,  // 死区 - 调参要点44
    .Derivative_LPF_RC = 0.02f,  // 微分滤波 - 调参要点45
}
```

- 触地检测阈值：20N
- 安全检查周期：10ms

**调参要点46-52：**
46. 姿态限位应比机械限位宽松
47. 速度限位考虑电机最大转速
48. 电流限位保护电机和驱动器
49. 触地阈值适应不同地面硬度
50. 检查周期平衡响应速度与计算负载
51. 急停减速度避免过大冲击
52. 所有限位参数需要实际测试验证

## 调参流程

### 阶段1：机械参数验证
1. 测量并记录所有机械参数
2. 验证运动学模型正确性
3. 检查关节限位设置

### 阶段2：单关节调试
1. 逐个调试关节电机PID
2. 验证关节角度反馈准确性
3. 测试关节运动范围和速度

### 阶段3：静态平衡调试
1. 调节LQR控制器参数
2. 实现静态站立平衡
3. 测试抗干扰能力

### 阶段4：步态调试
1. 从低速步态开始
2. 逐步增加运动速度
3. 优化步态参数

### 阶段5：综合测试
1. 测试各种运动模式
2. 验证安全保护功能
3. 记录最优参数组合

## 故障诊断

### 常见问题及解决方法

**问题1：系统振荡**
- 原因：增益过大或相位滞后
- 解决：减小比例增益，增加微分增益

**问题2：响应迟缓**
- 原因：增益过小或摩擦过大
- 解决：适当增加增益，检查机械摩擦

**问题3：步态失稳**
- 原因：步态参数不合适
- 解决：调整步态时序和轨迹参数

**问题4：电机过热**
- 原因：控制增益过大或机械卡滞
- 解决：降低控制增益，检查机械结构

## 总结

串联腿控制调参是一个迭代优化的过程，需要：

1. **系统性方法**：按照既定流程逐步调节
2. **详细记录**：记录每次调节的参数和效果
3. **安全第一**：始终在安全范围内进行测试
4. **实际验证**：所有参数都需要实际测试验证
5. **持续优化**：根据使用情况持续优化参数

建议先完成静态平衡调试，再逐步增加运动复杂度。遇到问题时，参考故障诊断部分进行排查。
