# chassis

## 工作流程

`ChassisTask()` 当前流程：

1. 读取 `chassis_cmd`（双板时从 CANComm 读取）。
2. 按模式做停机/使能控制。
3. 根据模式计算 `wz`（跟随/自旋/常规）。
4. 将云台系速度映射到底盘系。
5. 执行麦轮解算并设定各轮参考值。
6. 发布 `chassis_feed`（双板时通过 CANComm 回传）。

## 已完成迁移点

1. CAN 句柄与电机 ID 已统一读取 `robot_def.h`。
2. 电机方向、跟随增益、自旋参考值已参数化。
3. 底盘 PID 参数已参数化（速度环/电流环）。
4. 裁判串口与双板 CANComm 接口已参数化。

## 当前限制

1. 功率限制逻辑仍为预留位（尚未完整接入）。
2. 实际速度估计 `EstimateSpeed()` 仍是占位框架。
3. 平衡底盘需独立 app，不在当前 infantry 迁移范围。
